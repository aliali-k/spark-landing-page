# Spark Landing Page

Landing page है ना। एक काम कर, पहली बात scrollability का effect खत्म कर दो और interactive बना with different colors and impactful features add on करके। क्योंकि अभी जो है ना उसमें impactful features नहीं है। अरसद है? अरसद है? क्या कर रही है?

तो landing page बना और ऊपर से और अच्छा tool बना। अभी जो landing page है वो full effects का कम है और यह ठीक है explore, learn, create और वह सब community and यह about। ऊपर sign in, वह search वाला get started यह सब हटा दे और यह और AI वगैरह ठीक है और उसको single page बना ठीक है और interactive बना भी और सुंदर बना उसको क्योंकि अभी यह सुंदर नहीं है अभी काफी।
